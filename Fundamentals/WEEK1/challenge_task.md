**Challenge: "Understanding Java Basics"**

**Task:**

- **Write a Java program that:**
    - Prints **"Welcome to Java Programming!"** to the console.
    - Declares and initializes variables of different data types (int, double, boolean, String).
    - Performs a simple mathematical operation (e.g., sum of two numbers).
    - Uses an if-else statement to check if a number is even or odd.

**Expected Learning Outcomes:**

- Practice writing a Java program from scratch.
- Understand variable declaration and data types.
- Implement basic arithmetic operations and control structures.

**Bonus Challenge (For Fast Learners):**

**Modify the program to:**

- Accept user input using Scanner and display a personalized message.
- Calculate and display the square of an input number.
