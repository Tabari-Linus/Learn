**Challenge: Hands-on with Java Collections – ArrayList, HashSet, and HashMap**

**Scenario: Employee Management System**

You are developing an **Employee Management System** where you need to store, update, and retrieve employee details efficiently.

**Part 1: ArrayList (Ordered, Allows Duplicates)**

- **Use case:** Store a list of employee names.
- **Tasks:**
    - Add new employees to the list.
    - Remove an employee by name.
    - Retrieve an employee by index.
    - Sort and display all employees.

**Part 2: HashSet (Unique, Unordered)**

- **Use case:** Store unique employee IDs.
- **Tasks:**
    - Add new employee IDs.
    - Check if a specific employee ID exists.
    - Remove an employee ID.
    - Display all employee IDs.

**Part 3: HashMap (Key-Value Pair for Fast Lookups)**

- **Use case:** Store employee ID → name mapping.
- **Tasks:**
    - Add employees with ID as the key.
    - Retrieve an employee's name by ID.
    - Remove an employee by ID.
    - Display all employees with their IDs.
